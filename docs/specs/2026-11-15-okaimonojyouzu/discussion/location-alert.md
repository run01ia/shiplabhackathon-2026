# 位置情報アラートの方式

作成日: 2026-11-15
ステータス: 検討中

## 論点

位置情報による入店検知を、Web / PWA でどこまで実現できるか。フロントで完結できるか、バックも必要か。

## 選択肢（任意）

- ブラウザの Geolocation API で定期取得して判定する。
- ジオフェンス系の仕組みを使う (Web では制約が大きい可能性)。
- 店舗判定は Places API 等の外部サービスを使う。
