# 位置情報アラートの方式

作成日: 2026-11-15
ステータス: 決定

## 論点

位置情報による入店検知を、Web / PWA でどこまで実現できるか。フロントで完結できるか、バックも必要か。

## 選択肢（任意）

- ブラウザの Geolocation API で定期取得して判定する。
- ジオフェンス系の仕組みを使う (Web では制約が大きい可能性)。
- 店舗判定は Places API 等の外部サービスを使う。

## 決定

**アプリ起動時の位置確認方式**に決定 (2026-11-15)。

- Web / PWA では、バックグラウンドでの入店検知はできない。位置情報はアプリを開いている間しか取れない。
- よく行くスーパーの近くでアプリを起動したら、自動で買い物中の画面へ遷移する。
- コンビニの自動検知は見送る。必要なら手動ボタンで代替する。
- 仮決め: スーパーの登録は「今いる場所を登録」ボタンで緯度経度を保存する。距離のしきい値は約 200m。
- ゆうとの調査は、この方式で実現できるか (iOS Safari の許可の挙動、精度) の確認に絞る。

- 判定の要件: よく行くスーパー (登録済み) の入店判定 (B)、コンビニの入店判定 (C)。
