## 役割分担

優先度は A=絶対 / B=できれば / C=時間があれば。

- ゲーム関連
  - スコア算出の計算式 A
  - UI 設計 A
  - キャラクター素材 C (AI 画像生成。必須ではない)
  - 着せ替え画面 B
- フロント
  - ゲーム画面 A
  - 着せ替え画面 B
  - 買い物リスト作成画面 (予算含む) A
  - アラート B/C (フロント完結できなければバックも必要): スーパー検知 B、コンビニ検知 C
- バック
  - 買い物リスト CRUD A
  - ログイン A
  - 通貨管理テーブルと API (増減) A
  - ユーザーが購入した着せ替えの管理テーブルと CRUD A
- プレゼン発表者 (未定)
